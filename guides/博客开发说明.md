# 博客开发说明

本文档说明当前站点里博客文章应该怎么放、怎么写、怎么预览、怎么发布。

## 1. 内容放哪里

博客内容统一放在：

```text
src/content/blog/
```

当前内容集合配置在：

- [src/content.config.ts](/Users/wangbin/workspace/my-projects/wangbin3162.github.io/src/content.config.ts)

这个目录下支持：

- `*.md`
- `*.mdx`

建议：

- 普通技术文章优先用 `.md`
- 需要嵌入 Astro 组件时再用 `.mdx`

## 2. 一篇文章的最小结构

新建文件示例：

```text
src/content/blog/astro-blog-init.md
```

文件内容示例：

```md
---
title: 'Astro 博客初始化记录'
description: '记录个人站点从静态页迁移到 Astro 的过程'
pubDate: '2026-06-07'
updatedDate: '2026-06-07'
heroImage: '../../assets/blog-placeholder-1.jpg'
---

这里开始写正文。
```

## 3. frontmatter 字段说明

当前必填字段：

- `title`
- `description`
- `pubDate`

当前可选字段：

- `updatedDate`
- `heroImage`

字段说明：

- `title`：文章标题，会展示在列表页和详情页
- `description`：文章摘要，后续也会用于 SEO 与 RSS
- `pubDate`：发布时间，必须能被 Astro 解析成日期
- `updatedDate`：更新时间
- `heroImage`：头图，建议使用 `src/assets/` 下的图片

## 4. 文件命名建议

推荐命名方式：

- 全小写
- 使用英文或拼音
- 单词之间用 `-`

示例：

- `astro-blog-init.md`
- `vue3-component-thinking.md`
- `echarts-dashboard-practice.mdx`

不建议：

- 文件名里带空格
- 文件名频繁改动
- 直接用中文文件名做 slug

原因：

- 路由更稳定
- 链接更好维护
- 更方便后续做 RSS、分享和跳转

## 5. 图片怎么放

文章头图、插图建议放在：

```text
src/assets/
```

如果是文章专属图片，建议按主题分目录，例如：

```text
src/assets/blog/
src/assets/blog/astro/
src/assets/blog/vue/
```

头图引用示例：

```md
heroImage: '../../assets/blog/astro/cover.png'
```

注意：

- 路径相对当前文章文件写
- 不要继续依赖 `docs/images` 或 `docs/public`

## 6. Markdown 还是 MDX

用 `.md` 的场景：

- 纯文字
- 图片
- 代码块
- 列表和表格

用 `.mdx` 的场景：

- 需要插入 Astro 组件
- 需要更灵活的内容组合

当前仓库里已有 MDX 例子：

- [src/content/blog/using-mdx.mdx](/Users/wangbin/workspace/my-projects/wangbin3162.github.io/src/content/blog/using-mdx.mdx)

## 7. 本地写博客的流程

1. 在 `src/content/blog/` 新建文章
2. 补齐 frontmatter
3. 如果有头图或插图，先放到 `src/assets/`
4. 执行本地开发命令：

```bash
npm run dev
```

5. 打开博客列表页确认文章已出现
6. 打开文章详情页检查：

- 标题
- 日期
- 头图
- 正文排版
- 代码高亮

## 8. 发布前检查

发布前至少检查这些项：

- frontmatter 是否完整
- 日期格式是否正确
- 图片路径是否正确
- 文章列表页是否能看到新文章
- 文章详情页是否能打开
- `npm run build` 是否通过

构建命令：

```bash
npm run build
```

## 9. 推荐的写作习惯

- `description` 不要空，尽量写成一句完整摘要
- `pubDate` 保持真实发布时间
- 修改旧文时补 `updatedDate`
- 头图尽量统一尺寸和风格
- 正文一级标题不要重复写站点标题

## 10. 常见问题

### 文章没有显示在博客列表里

优先检查：

- 文件是否放在 `src/content/blog/`
- 扩展名是不是 `.md` 或 `.mdx`
- frontmatter 有没有写错

### 构建时报 frontmatter 校验错误

优先检查：

- `title` 是否是字符串
- `description` 是否是字符串
- `pubDate` 是否可解析
- `heroImage` 路径是否正确

### 图片不显示

优先检查：

- 图片是否真的放在 `src/assets/`
- frontmatter 的相对路径是否写对
- 文件名大小写是否一致
