# 丰县人事考试网 · 项目经验

**项目概况**
面向县人社局公开招聘全流程的 Vue3 后台管理系统，覆盖考试批次配置到拟录用公示全业务链。

**项目背景**
人事考试涉及报名、审核、缴费、考务、成绩与录用多环节，线下统计繁重、易错难追溯。目标是实现全流程线上化、单据模板化与操作可审计，提升效率与准确性。

**技术栈**
- 框架：Vue 3 / Vite 5 / Vue Router 4 / Pinia
- UI：bin-ui-design、sortablejs、wangEditor、高德地图
- 能力：Axios、Lodop/浏览器打印、PostCSS 主题系统
- 工程：ESLint + Prettier、动态路由、按钮级权限

**我的角色**
前端负责人，负责整个前端系统构建。

**负责内容**
- 设计动态路由与 RBAC 权限体系，基于后端菜单树生成路由并封装按钮级权限 Hook，实现双层管控。
- 搭建后台骨架，含 Layout、多页签 TagsView、keep-alive 缓存与可视化主题配置。
- 封装 useTable/useForm/useTree 通用 CRUD Hooks 与 BaseTable、批量选择、附件上传等组件，支撑 150+ 页面开发。
- 构建模板化打印与统一导出框架，覆盖准考证、签到簿、座位贴、报名表、成绩单等 17 类单据与 24 个导出场景。
- 实现笔试/面试/体测/总成绩的导入、排名递补与统计分析模块，支持批量导入与名单导出。

**优势与价值**
- 技术价值：Hooks 与组件化沉淀降低重复开发，权限路由可配置。
- 技术价值：模板化打印与异步导出解耦业务和版式。
- 业务价值：报名到录用全流程线上化，减少人工统计与纸质流转。
- 业务价值：数据可追溯、权限可控，降低考务差错与合规风险。

**简历亮点**
- 主导 Vue3 + Vite 后台从 0 到 1 搭建，落地动态路由与按钮级 RBAC，支撑 150+ 业务页面。
- 抽象通用 CRUD Hooks 与组件库，页面开发效率提升【待补充】%。
- 设计 HTML 模板 + 变量替换的打印引擎，兼容 Lodop 与浏览器打印，版式后台可配、免发版。
- 构建统一导出与异步记录中心，覆盖 24 个导出场景，效率提升【待补充】。
- 打通成绩导入—排名—递补—统计闭环，支撑笔试/面试/体测/总成绩多阶段考务。
