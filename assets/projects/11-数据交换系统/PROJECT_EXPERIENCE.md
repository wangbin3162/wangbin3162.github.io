# 项目经验：Visual-DXP 数据交换平台

## 项目概况
面向多源异构数据的一体化数据交换与集成管理平台前端。

## 项目背景
企业数据分散在各类数据库、文件、FTP/SFTP、消息队列与外部接口中，传统手工 ETL 脚本效率低、调度与监控割裂、权限与规则难以统一。平台目标是以可视化方式完成数据源接入、任务配置、作业编排与执行监控，降低数据集成门槛与运维成本。

## 技术栈
- 框架：Vue 3、Vite 3、Vue Router 4（Hash）、Pinia
- 可视化：bin-ui-design、@vue-flow、ECharts/bin-charts-next、bin-editor-next
- 数据工具：Axios、xlsx-js-style、vuedraggable、dayjs、html-to-image
- 工程化：ESLint + Prettier、GitLab CI、Vite 分包与路径别名

## 我的角色
前端负责人，负责整个前端系统构建。

## 负责内容
- 设计分层前端架构，统一注册路由、状态、指令、UI、图表与编辑器，沉淀通用/业务组件与复用 hooks。
- 实现角色驱动的动态路由与菜单，完成登录态、权限与版本许可校验。
- 主导交换作业可视化编排：基于 @vue-flow 自研节点、连线与校验体系，支持拖拽、拓扑排序与图片导出。
- 负责任务、数据源、接口、规则等核心模块，支持字段映射、批量导入导出与多类型数据源接入。
- 搭建执行监控与统计分析，基于 ECharts 与 Excel 导出构建【待补充】个报表。
