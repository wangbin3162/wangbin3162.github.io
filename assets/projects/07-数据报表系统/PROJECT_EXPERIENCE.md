# 报表设计平台 · 项目经验

## 项目概况

基于 Vue 3 + UniverJS 的企业级报表设计平台，覆盖数据报表设计、渲染预览、在线填报与财务报表设计。

## 项目背景

业务需把 Excel 式报表的设计、取数与填报搬到 Web，替代人工维护 Excel。原方式模板与数据耦合、动态行列难扩展、填报缺少校验，平台需提供可视化模板配置与提交校验闭环。

## 技术栈

- 框架：Vue 3、Vite 6、Pinia、Vue Router
- 表格：UniverJS 0.25（筛选/超链接/绘图/数据验证）、@visactor/vtable
- 能力：axios、exceljs、luckyexcel、SortableJS、localforage、driver.js、SSE 流式对话
- 规范：JavaScript ESM、ESLint + Prettier

## 我的角色

项目负责人 / 前端负责人，负责整个前端系统构建。

## 负责内容

- 主导报表设计器架构，抽象单元格级配置模型（动态行展开、横向分组/转置、左主格、动态合并、条件样式、字典映射、超链接），支撑复杂矩阵报表。
- 构建数据渲染管线（矩阵→行/列/合并/公式/校验），引入后端矩阵接口并保留本地兜底，1000 行转换耗时由 41ms 降至 20ms。
- 实现填报表单设计与提交闭环，完成字段类型规整、必填与字典校验、批量字段生成，覆盖【待补充】类模板。
- 封装 Excel 导入导出、跨标签页刷新、动态路由与 OAuth2 登录续期，统一持久化与请求拦截。

## 优势与价值

- 技术：以 UniverJS 为内核构建可配置报表引擎，配置模型与渲染管线解耦，便于后端接管矩阵计算。
- 性能：数据转换重构使公式处理耗时降 83%、合并处理降 82%，大矩阵渲染更稳。
- 业务：模板可视化配置加在线填报，降低报表搭建与数据收集成本，提升数据准确性。

## 简历亮点
