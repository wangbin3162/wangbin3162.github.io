# 智能体平台知识库 - 项目经验

## 项目概况
新小蝶 AI 知识库与智能体平台前端，一套代码支撑配置中心与多端对话两大应用。

## 项目背景
企业大模型接入、知识库检索与智能体配置长期分散，缺少面向业务的可视化平台。目标是沉淀知识库管理、模型与工具编排、多端对话能力，降低智能体构建与使用成本。

## 技术栈
- 框架：Vue 3 + Vite 7，多入口（admin / chat）
- UI：Element Plus、Tailwind CSS v4、SCSS
- 状态与路由：Pinia（AES 加密持久化）、Vue Router（Hash、模块化路由）
- 能力：Axios 分层拦截器 + SSE 流式读取、vue-i18n、ECharts、md-editor-v3、CodeMirror
- 工程化：@bin 内部组件库、自定义 Vite 插件、ESLint/Oxlint/Prettier

## 我的角色
负责整个前端系统构建。

## 负责内容
1. 搭建多入口工程与分层架构，统一封装请求、状态、权限、国际化能力，沉淀内部组件库。
2. 主导配置中心：智能体管理、知识库与文档解析、分段与命中测试、模型与工具、资源授权。
3. 实现对话端 PC/Mobile/Embed 多端适配，基于 SSE 流式渲染，支持语音输入、知识引用与历史会话。
4. 设计配置驱动的动态表单引擎与可视化构造器，替代硬编码表单，覆盖【待补充】类场景。
5. 将对话组件封装为 Web Component，支持第三方与 React 嵌入，接入【待补充】个业务方。

## 优势与价值
- 技术价值：一套前端双应用与内部组件库，降低重复开发成本。
- 工程价值：权限、请求、i18n 基建标准化，提升迭代效率【待补充】。
- 业务价值：打通知识库到智能体对话全链路，覆盖管理端与多端消费。

## 简历亮点
- 主导 AI 智能体平台前端从 0 到 1 架构设计，以 Vue 3 多入口方案统一配置中心与对话端，支撑 97+ 视图。
- 封装 Axios 分层拦截器与 SSE 流式读取，实现打字机式对话及中止、重生成交互。
- 自研配置驱动动态表单引擎与构造器，以 JSON 替代硬编码表单，开发效率提升【待补充】。
- 将对话能力打包为 Web Component，支持 React 等异构系统嵌入，拓展复用边界。
- 设计权限码/角色路由守卫与 v-access 指令，实现菜单与按钮级权限控制。
