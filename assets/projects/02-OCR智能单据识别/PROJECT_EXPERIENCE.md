# 智能识别（ocr-form-app）项目经验

## 项目概况
基于 Vue 3 的 AI 智能单据识别前端平台，覆盖表单设计、影像识别、结果比对与识别监控。

## 项目背景
单据录入依赖人工逐项核对，效率低、易错；企业需将纸质票据、包装图等非结构化影像转为结构化数据并接入业务系统。目标是提供“设计模板—上传识别—比对校验—日志统计”一体化工具，降低录入成本、提升准确率。

## 技术栈
- 框架：Vue 3（`<script setup>`）+ Vite 7
- 状态/路由：Pinia 3 + persistedstate、Vue Router 4（hash + 守卫）
- UI/样式：bin-ui-design、Tailwind CSS v4、Lucide / Element Plus Icons
- 设计器：fc-design（form-create）+ vuedraggable
- 基础能力：axios 封装、socket.io-client、qrcode、html2canvas

## 我的角色
负责整个前端系统构建。

## 负责内容
- 搭建 Vue 3 + Vite 工程基座，统一请求封装、Pinia 状态分层与 Hash 路由守卫，支撑【待补充】个业务模块。
- 集成可视化表单设计器，封装全屏设计面板与旧 `form_json` 兼容适配层，实现模板在线拖拽设计。
- 设计文件拖拽、摄像头/高拍仪拍照裁剪、手机扫码上传的多源链路，经 OCR 回填动态表单。
- 落地图片 OCR 对比（双侧裁剪 + 差异可视化）与识别日志 KPI 统计、检索及详情追溯。
- 构建角色 + 权限码的递归多级菜单鉴权，迁移主题配置、暗黑模式、多标签页等布局体系。

## 优势与价值
- 技术价值：设计器与动态渲染解耦，模板即配置，降低新增单据的开发成本。
- 技术价值：统一请求层与权限守卫，模块接入规范一致，可维护性高。
- 业务价值：多源上传与日志统计形成闭环，辅助定位失败原因、优化识别准确率【待补充】。
- 业务价值：人工录入转为自动回填，缩短单据处理周期【待补充】。
