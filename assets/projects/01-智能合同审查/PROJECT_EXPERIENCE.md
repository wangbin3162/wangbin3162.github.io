# 合同管理平台 · 项目经验

## 项目概况
面向企业法务的 AI 合同管理平台，覆盖台账提取、智能审查、版本对比与规则/条款资产库。

## 项目背景
企业合同录入依赖人工、审查依赖个人经验、多版本差异难追踪，且大模型整篇处理易超上下文漏审。平台以规则库约束大模型，实现自动提取、合规审查与差异分析，目标提取准确率≥85%、单份≤30 秒。

## 技术栈
- 前端：Vue 3、Vite、Pinia、Vue Router、Tailwind CSS v4、ECharts、Vue Flow、OnlyOffice
- 后端：FastAPI、SQLAlchemy 2.x（async）、PostgreSQL、Alembic、Redis、Nacos
- AI 与文档：OpenAI 兼容大模型、统一文档解析底座、NDJSON 流式协议

## 我的角色
项目负责人 / 前端负责人，主导全模块设计与开发。

## 负责内容
- 主导 Vue 3 前端工程搭建与分层，基于 Pinia + Axios 拦截器实现 JWT 鉴权、路由守卫与统一 API 层。
- 设计合同审查：规则按章节打分分发、章节并发精读、结果面板与 DOCX 单条采纳回写，耗时【待补充】。
- 构建台账对话式提取：流式分步进度、19 项字段双批并发、条款原文锚点回验，准确率【待补充】。
- 实现合同对比：段落级 + 词级双粒度差异、分批 AI 变更分析，覆盖【待补充】份。
- 搭建 FastAPI 服务端分层与统一 LLM 调用收口（超时、重试、清洗），配套 148 条 pytest 用例。

## 优势与价值
- 技术价值：统一文档解析底座与 NDJSON 流式协议，三链路复用解析与事件规范。
- 技术价值：规则驱动审查，结论可回溯到规则与法律依据。
- 业务价值：提取、审查、对比全流程自动化，降低人工与法务审阅成本。
- 业务价值：文件版本、状态日志与采纳记录全程留痕，满足合规审计要求。
