# 项目经验：企业级数据分析与 BI 平台

**项目概况**
企业级一站式数据分析平台前端系统，贯通数据建模、可视化搭建、智能问数与报告输出。

**项目背景**
数据分散多源、业务难以自助建模与搭看板、取数报表依赖研发；目标是以可视化构建低门槛自助分析平台，前端独立承载全部交互与渲染。

**技术栈**
- 框架：Vue 3、Vite 2、Vue Router 4、Pinia
- 可视化：ECharts 5、@vue-flow
- 数据与导出：ExcelJS、SheetJS、html2canvas、jsPDF
- 交互与流式：vxe-table、SortableJS、fetch-event-source（SSE）
- 工程化：ESLint/Prettier、懒加载与分包

**我的角色**
负责整个前端系统构建（约 28 万行、2122 个文件）。

**负责内容**
- 主导数据建模前端：数据源管理与存储元数据四种编辑流、字段质量/安全/业务配置与版本对比，覆盖【待补充】类数据源。
- 设计 OLAP 多维建模引擎：拖拽多表 Join、自定义 SQL（CTE）、Excel/CSV、API 四种建模，产出维度/度量与计算字段。
- 从零搭建可视化页面搭建器：拖拽组件库 + 画布 + 属性/样式/数据/事件四区配置，JSON 持久化，三态渲染，沉淀 60+ 组件。
- 构建主题分析、指标/标签管理、即席查询、智能问数等 70+ 模块，统一权限、编辑锁与接口层。

**优势与价值**
- 以 JSON Schema + 渲染管线解耦配置与渲染，新增组件零改路由，扩展性强。
- 事件总线 + 组件脚本实现图表/表格/容器跨组件联动，复杂分析可配置化。
- 业务人员自助建模与拖拽搭建看板，降低研发取数依赖。
- 覆盖建模到报告导出闭环，服务经营与财务分析，支撑【待补充】用户。

**简历亮点**
- 主导 28 万行级 BI 平台前端从 0 到 1，抽象建模—搭建—分析—报告全链路，交付 70+ 模块。
- 设计 JSON 驱动可视化搭建器与 60+ 组件体系，import.meta.glob 自动注册，组件接入零改造。
- 实现四模 OLAP 建模引擎（Join/SQL/文件/API），前端完成维度度量与计算字段建模。
- 事件总线 + 脚本钩子实现跨组件联动；以编辑锁、撤销重做、分包保障协同与首屏性能。
