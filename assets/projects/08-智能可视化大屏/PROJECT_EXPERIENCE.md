# 项目经验 · 大屏分析设计器

**项目概况**
基于 Vue 3 + Vite 5 的低代码大屏可视化分析设计平台，拖拽组件、配置数据源与事件联动，保存 schema 后一键预览与分享。

**项目背景**
内部运营/分析人员搭建数据大屏长期依赖前端逐屏开发，周期长、复用差。平台以可视化编辑器替代硬编码，让非开发人员自助产出大屏。

**技术栈**
- 框架：Vue 3（Composition API）、Vite 5、Vue Router、Pinia
- 可视化：ECharts 5（GL/liquidfill/wordcloud）、bin-charts-next、Three.js、@vue-flow
- 交互与工具：SortableJS、GSAP、animate.css、mitt、md-editor-v3、dom-to-image
- 工程化：ESLint + Prettier、GitLab CI、多环境构建、manualChunks 拆包

**我的角色**
项目负责人 / 前端负责人，负责整个前端系统构建。

**负责内容**
- 设计可视化画布编辑器：标尺、吸附对齐、缩放、框选、组合解组、图层，支撑 40 类组件拖拽编排。
- 搭建组件配置体系：统一 config.js/config.vue/main.vue/index.js 四件套与注册机制，沉淀 14 大类图表/控件/3D/拓扑组件。
- 封装 useDataCenter 统一数据装配层，收敛静态/模型/接口三类数据源，支持下钻上卷与轮询刷新。
- 基于 mitt 构建事件总线与自定义脚本，打通组件事件到动作绑定及跨组件联动。
- 落地运行时与协作：缩放适配、编辑锁心跳、schema 保存导入导出、模板与分享；主导 AI 智能解读面板（流式输出+语音输入），【待补充】使用率指标。

**优势与价值**
- 低代码 schema 驱动，组件与数据、事件解耦，新增组件三处注册即复用，扩展成本低。
- 编辑态与运行态双模式渲染，保证配置所见即所得。
- 非开发人员自助搭建大屏，缩短交付周期【待补充】%。
- AI 解读降低报表理解门槛，提升分析效率。

**简历亮点**
- 主导 Vue3 大屏设计器前端架构，以 schema + 双模式渲染支撑 40 类、14 分类组件编排。
- 设计 useDataCenter 统一数据装配层，收敛三类数据源并支持下钻轮询，减少重复代码【待补充】%。
- 基于 mitt 事件总线实现跨组件联动与脚本扩展，拖拽即联动的可视化配置。
- 实现编辑锁与心跳续约，解决多人并发编辑冲突。
- 从零主导 AI 智能解读面板，流式渲染 + 语音输入，将报表解读转为即时生成。
