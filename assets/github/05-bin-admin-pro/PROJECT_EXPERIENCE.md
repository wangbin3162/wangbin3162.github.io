# 项目经验：BIN-ADMIN-PRO 企业级中后台前端框架

**项目概况**
基于 Vue3 与 Vite 构建的企业级中后台前端框架，沉淀权限、布局、主题与可视化编辑能力，作为管理类系统的统一底座。

**项目背景**
中后台系统重复搭建布局、权限、表格表单与主题样式，成本高且风格不一。项目目标是提供开箱即用、可配置、可扩展的统一方案，缩短业务系统交付周期。

**技术栈**
- 框架：Vue 3.5、Vite 5、Vue Router 4、Pinia
- UI 与组件：bin-ui-design、bin-editor-next、bin-charts-next、ECharts
- 可视化与办公：luckysheet/luckyexcel、Vue Flow、jsPlumb、ExcelJS
- 工程化：ESLint + Prettier、PostCSS、rollup 分包

**我的角色**
项目负责人 / 前端负责人，负责整个前端系统构建。

**负责内容**
- 搭建应用分层架构（api/components/hooks/layouts/pinia/router/theme），统一入口、插件与指令注册。
- 设计动态路由与菜单权限体系，依据后端权限生成路由，结合白名单校验与多页签缓存联动。
- 封装 useTable/useForm/useTree 业务 Hook 及 BaseTable/BaseTree 通用组件，覆盖【待补充】个业务页面。
- 实现基于 CSS 变量与 PostCSS 的可视化主题系统，支持实时预览、配置导出与本地缓存。
- 开发 Excel 模板设计、Schema 画布与流程编排等可视化模块，支撑数据填报与流程配置场景。

**优势与价值**
- 技术价值：分层清晰、Hook 化复用，显著降低重复开发与维护成本。
- 主题以 CSS 变量驱动，换肤零侵入且实时生效。
- 可视化编辑降低配置门槛，非技术人员可完成模板与流程搭建。
- 工程规范统一，构建分包优化首屏，加载性能提升【待补充】。
