# 项目经验：Excel Pro 在线报表设计平台

## 项目概况
基于 Univer Sheet 的在线 Excel 报表平台，覆盖模板设计、数据渲染与在线填报全流程。

## 项目背景
传统报表依赖 Excel 手工排版，模板难以复用、数据靠人工填充、格式易出错且发布不统一。平台目标是让业务人员可视化设计模板，绑定数据集后一键渲染或填报，降低报表制作与维护成本。

## 技术栈
- 框架：Vue 3、Vite 5、Vue Router、Pinia
- 表格引擎：Univer Sheet、exceljs、luckyexcel、file-saver
- UI/样式：bin-ui-design、PostCSS 变量主题
- 工程化：ESLint、Prettier、localforage、BroadcastChannel

## 我的角色
项目负责人 / 前端负责人，负责整个前端系统构建。

## 负责内容
- 封装 Univer 插件层与实例 API，实现插件注册、选区与单元格操作、编辑权限锁定、工作簿快照读写。
- 设计 `${对象.字段}` / `#{列表.字段}` 占位语法，实现字段拖拽绑定、数据集与字典映射、动态合并配置。
- 构建渲染处理链（单元格填充、公式区间重写、动态合并、校验迁移），支撑列表逐行展开与公式联动。
- 打通 Excel 导入转换与导出还原，覆盖样式、合并、图片与数据校验。
- 搭建报表增删改查与发布、跨标签页联动，沉淀 useTable 等通用 hooks。

## 优势与价值
- 自研占位解析与公式重算，复杂列表报表可正确展开并保持引用。
- 字典映射、动态合并与自定义脚本，让业务人员可配置渲染逻辑。
- 动态路由、主题变量与组件库统一，新页面接入成本低。
- 报表由人工排版转为模板化配置，交付周期缩短【待补充】%。

## 简历亮点
- 主导 Univer Sheet 集成，封装表格插件层，实现设计/预览/填报三端复用。
- 设计占位协议与渲染处理链，完成列表展开、公式重写与动态合并。
- 基于 LuckyExcel 与 exceljs 打通导入导出，还原合并、样式与数据验证。
- 抽象通用 hooks 与组件，提升团队复用与交付效率【待补充】。
- 搭建动态权限路由与 CSS 变量主题体系，支撑多项目快速复用。
