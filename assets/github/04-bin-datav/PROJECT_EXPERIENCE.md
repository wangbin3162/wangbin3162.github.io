# 项目经验：bin-datav-schema 数据大屏可视化搭建平台

**项目概况**
基于 Vue3 的可视化大屏设计器，支持拖拽搭建、多数据源接入与一键预览发布的分析型 BI 平台。

**项目背景**
传统大屏开发依赖前端逐页手写代码，重复劳动多、交付周期长，业务方无法自主调整。平台以「低代码搭建 + 多数据源」为核心，让运营与分析师通过拖拽配置即可完成大屏制作，降低开发成本、提升交付效率。

**技术栈**
- 框架：Vue 3.4、Vite 5、Pinia、Vue Router 4
- 可视化：ECharts 5（gl/liquidfill/wordcloud/stat）、Three.js、Vue Flow
- 工程：bin-ui-design、bin-charts-next、bin-editor-next、GSAP/animate.css、axios + mock

**我的角色**
负责整个前端系统构建，主导架构设计、核心编辑器与全部业务组件开发。

**负责内容**
- 设计 schema-editor 分层架构，画布、组件面板、配置面板、图层面板解耦，Store 按 page/canvas/compose/snapshot 拆分状态。
- 实现画布交互引擎：基于 dv-transform 完成拖拽、缩放、旋转、多选组合，配合 mark-line 吸附对齐、标尺与撤销/重做快照（上限 20 步）。
- 搭建数据中心 Hook，统一静态/接口/模型三类数据源，支持字段映射、下钻、轮询刷新与系列数自适应。
- 封装事件总线与响应配置，实现组件间联动（点击/筛选触发），并沉淀图表主题与自定义配色体系。
- 建设 40+ 大屏组件（图表、控件、3D 地球/楼宇等），支持页面 JSON 序列化保存与预览等比自适应。【待补充：组件数量与性能指标】

**优势与价值**
- 技术上形成「编辑器内核 + 组件规范 + 数据协议」可复用底座，新增组件仅需配置即可接入。
- 业务上把大屏交付从编码转为配置，缩短周期、降低人力，非技术用户可自助改版。

**简历亮点**
- 主导 Vue3 大屏低代码编辑器从 0 到 1 架构设计，抽象画布/配置/数据三层模型，支撑 40+ 组件规模化扩展。
- 自研画布交互内核，实现拖拽缩放旋转、吸附对齐、多选组合与快照撤销，交互体验对齐专业设计工具。
- 构建多数据源数据中心与事件联动机制，打通静态/模型数据与组件钻取、轮询、联动场景。
- 沉淀全局主题与图表配色系统，统一视觉规范并支持业务自定义皮肤。
