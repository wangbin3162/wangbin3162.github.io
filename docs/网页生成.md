# 角色
你是一位资深前端工程师兼 UI 设计师，擅长制作简约高级的个人简历站点。

# 任务
根据我提供的个人信息与项目经历素材，制作一个单页网页版个人简历站点，输出完整可运行代码。

# 视觉风格
- 主体白色背景，简约大方，留白充足，信息层级清晰
- 毛玻璃（backdrop-filter blur）用于卡片/导航等局部，克制使用
- 禁止使用紫色渐变；整体配色以白、浅灰、深灰/近黑为主，可用单一低饱和强调色点缀
- 尽量少用悬停图片，交互以滚动与排版为主
- 字体排版优先，标题与正文对比明确

# 内容结构（按顺序）
1. Hero：姓名、职位（前端 Leader / 部门负责人）、一句话定位、联系方式
2. 个人优势：3-5 条能力标签 + 简短说明，突出技术深度与管理能力
3. 项目经历：重点项目卡片列表，每项含项目名、角色、技术栈、亮点 bullet（3-4 条）
4. 技能栈：分类展示
5. 教育与其他（如有）
6. 页脚联系方式

# 功能要求
- 滚动动画：进入视口淡入/上移，使用 IntersectionObserver 实现，尊重 prefers-reduced-motion
- 移动端适配：响应式布局，断点至少覆盖手机/平板/桌面
- 导航：简洁锚点导航，移动端可折叠
- 性能：无重型依赖，优先原生 CSS/JS；图片懒加载
- 可访问性：语义化标签、对比度达标、键盘可操作

# 技术要求
- 单文件 HTML（内联 CSS/JS）或明确说明文件拆分
- 不引入不必要框架；如用 CDN 需说明
- 代码整洁、有注释、可直接打开运行

# 输出
- 先给页面结构与视觉方案简述（不超过 10 行）
- 再输出完整代码
- 最后说明如何替换个人数据、如何部署
