pnpm add gsap @studio-freight/lenis

```bash
pnpm add @barba/core
```

| 库 | 版本 | 用途 | 大小(gzip) |
|---|---|---|---|
| `@barba/core` | ^2.x | SPA 页面过渡 | ~7KB |

```bash
pnpm add swiper
```

| 库 | 版本 | 用途 | 大小(gzip) |
|---|---|---|---|
| `swiper` | ^11.x | 首页项目水平轮播（移动端） | ~40KB |

## 5. 交互设计

### 5.1 首页交互流程

```
[页面加载]
  → Canvas 粒子背景启动
  → Hero 标题字符逐个揭示 (GSAP stagger 50ms)
  → 统计数字和标签淡入

[向下滚动]
  → Projects 轮播区域进场 (ScrollTrigger)
  → 轮播自动运行，hover 暂停
  → What I Do 区块进场 (ScrollTrigger)
  → Experience 区块进场 (ScrollTrigger)

[点击项目]
  → 轮播中的项目可点击 → 跳转 /project/:slug
  → Barba.js 过渡动画执行

[点击导航]
  → 跳转 /project 或 /about
  → Barba.js 过渡动画执行
```

### 5.2 作品集交互流程

```
[页面加载]
  → 编号列表进场动画 (字符从下方滑出)
  → 无限循环滚动启动

[hover 项目行]
  → 行标题变 --accent 色
  → 右侧浮出项目缩略图 (opacity 0→1, translateX)
  → 循环滚动暂停

[离开 hover]
  → 恢复原色，图片消失
  → 循环滚动恢复

[点击项目]
  → 跳转 /project/:slug
  → Barba.js 过渡
```

### 5.3 关于页交互流程

```
[页面加载]
  → 简介文字揭示
  → TEAM 区块进场
  → 各区块依次进场 (ScrollTrigger stagger)

[滚动到 Skills]
  → 技能分类卡片依次进场

[滚动到 Contact]
  → 联系方式进场
```

### 5.4 页面过渡机制

**Barba.js + GSAP 过渡层设计**：

```
[点击导航链接]
  → Barba.js 拦截点击，阻止默认导航
  → 离开动画：当前页面内容淡出 (opacity → 0, 300ms)
  → 过渡遮罩：全屏黑色层从底部滑入 (600ms, ease-out)
  → 新页面 HTML 通过 fetch 获取并注入
  → 进入动画：遮罩从顶部滑出 (600ms, ease-out)
  → 新内容从下方位移进场 (600ms, ease-spring)
  → 新页面的 GSAP/Lenis 初始化
  → 过渡完成
```

**关键实现细节**：
- `data-barba="wrapper"` 包裹整个 `<main>`
- `data-barba="container"` 每个页面的 `<main>` 内容区
- `data-barba-namespace="home"` / `"project"` / `"about"` 标识页面
- 过渡完成后需重新初始化 ScrollTrigger 和 Lenis
- 粒子背景 Canvas 可跨页面保持（不随 Barba 过渡销毁）

## 7. 实现难点与解决方案

### 7.1 Barba.js 与 Astro SSG 的兼容

**难点**：Astro 输出静态 HTML，Barba.js 需要 SPA 行为。Astro 默认的多页面应用模式下，页面间跳转是完整的 HTML 请求。

**解决方案**：
- Barba.js 通过 `fetch` 获取新页面的 HTML，只替换 `[data-barba="container"]` 的内容
- 需确保 Astro 页面都使用统一的 Layout，`<head>` 和 `<script>` 标签一致
- Barba.js 的 `prevent` 规则需要阻止外部链接和非页面链接
- 过渡完成后需重新运行新页面的初始化脚本（GSAP、Lenis、ScrollTrigger）

**具体做法**：
```js
barba.init({
  prevent: ({ el }) => el.classList.contains('no-barba') || el.href.startsWith('#'),
  transitions: [{
    leave(data) { /* GSAP 淡出 */ },
    enter(data) { /* GSAP 淡入 */ },
    after(data) { /* 重新初始化 */ }
  }]
})
```

### 7.2 Lenis 与 GSAP ScrollTrigger 的联动

**难点**：Lenis 替换了浏览器默认滚动行为，ScrollTrigger 依赖滚动位置触发动画。

**解决方案**：
```js
const lenis = new Lenis()

// 同步 Lenis 到 ScrollTrigger
lenis.on('scroll', ScrollTrigger.update)

// 让 GSAP 使用 Lenis 的 raf 循环
gsap.ticker.add((time) => lenis.raf(time * 1000))
gsap.ticker.lagSmoothing(0)
```

### 7.3 无限循环滚动

**难点**：项目列表的垂直无限循环需要无缝衔接。

**解决方案**：
1. 将完整列表内容复制一份，拼接在原列表下方
2. CSS 动画 `translateY(0)` → `translateY(-50%)`（50% 因为内容翻倍了）
3. 动画到达 50% 位置时视觉上无缝回到起点
4. hover 时暂停动画 (`animation-play-state: paused`)
5. 触摸设备上 touchstart 暂停，touchend 恢复

```css
.project-list-track {
  animation: verticalScroll 40s linear infinite;
}
.project-list-track:hover {
  animation-play-state: paused;
}
@keyframes verticalScroll {
  from { transform: translateY(0); }
  to { transform: translateY(-50%); }
}
```

### 7.4 文字揭示动画（无 SplitText）

**难点**：GSAP 的 SplitText 是付费插件。

**解决方案**：自行实现字符拆分逻辑：
```js
function splitText(element) {
  const text = element.textContent
  element.innerHTML = text.split('').map(char =>
    `<span class="char" style="opacity:0; transform:translateY(30px)">${char === ' ' ? '&nbsp;' : char}</span>`
  ).join('')
  return element.querySelectorAll('.char')
}

// 使用 GSAP 动画
gsap.fromTo(splitText(el), {
  opacity: 0, y: 30
}, {
  opacity: 1, y: 0, stagger: 0.05, duration: 0.6, ease: 'power2.out'
})
```

### 7.5 Canvas 粒子背景性能

**难点**：全屏 Canvas 粒子动画在低端设备上可能卡顿。

**解决方案**：
- 使用 Canvas 2D（不使用 WebGL/Three.js），性能开销更低
- 粒子数量动态调整：桌面 150 个，移动 30 个
- 使用 `requestAnimationFrame` + 离屏渲染
- 页面不可见时暂停动画（`IntersectionObserver` 或 `visibilitychange`）
- 粒子连线距离阈值 ≤ 120px，避免过多连线计算

### 7.6 Hover 图片浮现效果

**难点**：项目列表 hover 时需要在右侧浮现图片，图片需要预加载。

**解决方案**：
1. 所有项目图片使用 Astro 的 `<Image>` 组件预优化为 WebP
2. hover 时通过 Vue reactive 数据切换当前 hover 项目
3. 图片容器使用绝对定位在右侧，`opacity: 0 → 1` + `translateX(20px → 0)`
4. 图片预加载：页面加载时所有图片用 `<link rel="preload">` 预加载

### 7.7 页面过渡后重新初始化

**难点**：Barba.js 替换页面内容后，GSAP ScrollTrigger 和 Lenis 需要重新初始化。

**解决方案**：
```js
// Barba.js after hook
after(data) {
  // 销毁旧 ScrollTrigger
  ScrollTrigger.getAll().forEach(st => st.kill())

  // 重新初始化 Lenis
  lenis.destroy()
  lenis = new Lenis()
  lenis.on('scroll', ScrollTrigger.update)
  gsap.ticker.add((time) => lenis.raf(time * 1000))

  // 执行新页面的初始化函数
  initPageAnimations(data.next.namespace)
}
```
